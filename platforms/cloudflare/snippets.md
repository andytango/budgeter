# Cloudflare: snippets for the Claude side

Paste these blocks into the user's `CLAUDE.md` and daily routine prompt (see AGENTS.md, phase 4),
with the placeholders filled in. The routine's environment needs `CLOUDFLARE_API_TOKEN` (D1 Edit is
enough) and `CLOUDFLARE_ACCOUNT_ID`, or the Cloudflare connector (it can query D1).

`$D1` below = `https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/d1/database/<D1_DATABASE_ID>/query`,
called with `-H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" -H "content-type: application/json"`
and a body `{"sql": "...", "params": [...]}`. Build bodies with `jq` or Node from files; never retype JSON.

## MEMORY (for CLAUDE.md)

```markdown
- Phone app: https://<DOMAIN> (Cloudflare Worker `budgeter`, behind Cloudflare Access; allowed: <EMAIL>).
  Code: `<APP>` (generated by Budgeter's tools/create.mjs; update with `--update`, deploy with `npx wrangler deploy`).
- D1 database `budgeter-db` (id `<D1_DATABASE_ID>`): `docs` row `current` = the budget JSON (column `body`, text);
  `push_subs` = my devices; `notifications` = outgoing pushes (insert a row to notify my phone; a future
  `created_at`, in UTC, schedules it). Data changes need no deploy.
- Credentials: env vars `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`.
```

## READ (routine: get the budget)

```
POST $D1 {"sql": "SELECT body FROM docs WHERE id = 'current'"}  →  result[0].results[0].body (JSON text)
```
Save it to a file and edit the file.

## WRITE (routine: save the budget)

Validate first: `node <BUDGETER>/tools/validate.mjs <file>` (fix every error; itemise any gap).

- Daily update, everything except history:
  `{"sql": "UPDATE docs SET body = json_patch(body, json(?)), updated_at = datetime('now') WHERE id = 'current'", "params": [<the document WITHOUT history, as a JSON string>]}`
- Payday rollover, first append the finished period, guarded so it can't happen twice:
  `{"sql": "UPDATE docs SET body = json_insert(body, '$.history[#]', json(?)), updated_at = datetime('now') WHERE id = 'current' AND json_array_length(body, '$.history') = ?", "params": [<finished period JSON>, <history count before>]}`
- Check: `{"sql": "SELECT json_valid(body), json_extract(body, '$.asOf'), json_array_length(body, '$.history') FROM docs WHERE id = 'current'"}`.
  (D1 stores 45 as 45.0, so compare fields, not string lengths.)
- With only the Cloudflare connector: nest `json_set` / `json_insert` / `json_remove` inside ONE
  assignment to `body` (SQLite keeps only the last assignment to a column), guarded with
  `json_extract` checks.

## NOTIFY (routine: push to the phone)

```
POST $D1 {"sql": "INSERT INTO notifications (title, body, url) VALUES (?, ?, '/')", "params": ["Budget", "<text>"]}
```
Scheduled: add `created_at` in UTC, e.g. `'2026-10-01 07:00:00'`. Sent within a minute. Check:
`SELECT sent_at, result FROM notifications ORDER BY id DESC LIMIT 1` (`no devices` = notifications
aren't on yet: remind the user about the bell once).
